========================================================================
                      JARVECRAFT CUSTOM PAINTINGS
========================================================================

Drop any images you want to appear in Minecraft here!

You can drop images (.png, .jpg, .jpeg) in any of the following ways:

Option A: Drop directly into this 'paintings/' folder
- Any image name works (e.g. 'my_photo.png', 'meme.jpg', 'cool_art.png').
- JarveCraft will automatically check the aspect ratio:
  - Square (~1:1)       -> 1x1, 2x2, or 4x4 painting slots
  - Landscape (~2:1)    -> 2x1 or 4x2 painting slots
  - Large Landscape     -> 4x3 painting slots
  - Portrait (~1:2)     -> 1x2 painting slots

Option B: Drop into subfolders (Optional, for specific sizes)
- paintings/square/     -> For 1:1, 2x2, 4x4 paintings
- paintings/landscape/  -> For 2x1, 4x2, 4x3 paintings
- paintings/portrait/   -> For 1x2 paintings

Option C: Specific vanilla painting names (Optional)
If you want an image to replace a specific vanilla painting slot, name it
after that painting:
- 1x1: kebab.png, aztec.png, alban.png, aztec2.png, bomb.png, plant.png, wasteland.png
- 2x1: pool.png, courbet.png, sea.png, sunset.png, creebet.png
- 1x2: wanderer.png, graham.png, prairie_ride.png
- 2x2: bust.png, match.png, skull_and_roses.png, stage.png, void.png, wither.png
- 4x2: fighters.png, changing.png
- 4x3: pointer.png, pigscene.png
- 4x4: skeleton.png, burning_skull.png, donkey_kong.png

When you place a painting in Minecraft:
Only your custom images will be placed, chosen at random from the ones that fit!
